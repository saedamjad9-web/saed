# داش بورد المبيعات اليومية

داش بورد بسيط بـ Flask لعرض المبيعات اليومية مع الكلفة والربح بالدولار والدينار العراقي لكل فاتورة.

## التشغيل

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح: http://localhost:5000

## بيانات الفواتير

الفواتير مخزّنة في `data/invoices.csv` بالأعمدة التالية:

| العمود       | الوصف                  |
|--------------|------------------------|
| `invoice_id` | رقم الفاتورة           |
| `date`       | تاريخ الفاتورة (YYYY-MM-DD) |
| `customer`   | اسم العميل             |
| `sale_usd`   | سعر البيع بالدولار     |
| `sale_iqd`   | سعر البيع بالدينار     |
| `cost_usd`   | الكلفة بالدولار        |
| `cost_iqd`   | الكلفة بالدينار        |

يمكن استبدال الملف بـ Excel (`.xlsx`) عبر تحديث المسار في `app.py`.

## الميزات

- بطاقات إجمالية: عدد الفواتير، المبيعات، الكلفة، الربح (بالعملتين).
- رسمين بيانيين يوميين (دولار ودينار) للمبيعات/الكلفة/الربح.
- جدول ملخص يومي وجدول تفصيلي لكل فاتورة.
- تصفية حسب نطاق التاريخ.
